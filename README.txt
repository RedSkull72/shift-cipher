# Caesar Cipher 

This project encrypts and decrypts some plain texts by using one of the classic encryption algorithms called Caesar (shift) Cipher.

## Features

- **Encryption** Cryptes the plain text by shifting it by using the defined key number.
- **Decryption** Decryptes the crypted text by using the same key that is used in the encryption process.

## Usage
After cloning the project you can run it from terminal directly with this command:

```bash
python shiftCipher.py
